## 변경한 디자인

- 원본의 중앙 정렬 표지와 표지의 학교 로고
- 왼쪽 파트 번호·제목 / 오른쪽 안내로 나눈 섹션 페이지
- 남색 섹션 번호 배지, 제목 구획선, 소제목 강조 표시
- 남색 그림·도식·표 머리글과 KEY POINT 메시지 영역
- 원본 목차에서 사용한 모서리 선을 재해석한 목차·Q&A 배치

본문 배경은 흰색이며, 남색 면은 정보 구분용 머리글/배지에만 사용했습니다. 일반 텍스트는 검정 중심, Arial Bold 24pt 이상입니다. 표지 이외의 로고는 없습니다. 사방 여백과 하단 중앙 쪽번호는 유지했습니다.

## 사용법

필요한 슬라이드를 복제하고 대괄호 문구를 교체하세요. 표지의 연구실명과 본심 날짜는 입력해야 합니다. 그림·표·도형은 편집할 수 있습니다. 원래 세미나의 연구 내용과 결과 사진은 제거했으며 가상 성능 수치는 넣지 않았습니다.

새 그림을 넣을 때도 그림 속 글자와 선 크기를 확인하세요. 실제 발표 PC의 PowerPoint에서 Arial 글꼴과 줄바꿈을 최종 확인해 주세요.
