# 성균관대학교 박사논문 발표 템플릿

성대 발표 가이드에 맞춘 24장 편집용 템플릿입니다.

- [PowerPoint 파일 다운로드](SKKU_PhD_Defense_Template.pptx?raw=true)
- [PowerPoint 서식 파일 다운로드](SKKU_PhD_Defense_Template.potx?raw=true)
- [PDF 미리보기](SKKU_PhD_Defense_Template.pdf)

파일 화면에서 **Download raw file** 아이콘을 눌러 저장할 수도 있습니다.

흰색 배경, Arial Bold 24pt 이상, 사방 5mm 이상 여백, 하단 중앙 쪽번호를 적용했습니다. 기존 세미나 본문은 제거하고 편집용 자리표시자로 바꿨습니다. 필요한 슬라이드를 복제하고 대괄호 내용을 바꿔 사용하세요. 표지의 연구실명과 발표일은 입력해야 합니다.

구성: 표지 → 목차 → 서론 → 관련 연구 → 제안 프레임워크 → 실험/결과 → 결론/향후 연구 → Q&A.

실제 발표 PC에서 Arial 글꼴과 줄바꿈을 최종 확인하세요.
