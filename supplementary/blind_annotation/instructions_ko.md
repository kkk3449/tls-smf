# 독립 라벨링 안내 (T3 세트, 41개)

안녕하세요. 3D 스캔에서 자동으로 분리된 물체 후보 41개에 대해, **각각이 실제로 어떤 물체인지** 적어 주시는 작업입니다. 예상 소요 시간은 30–60분입니다.

**중요: 이 시트에는 시스템이 추정한 라벨이 전혀 포함되어 있지 않으며, 다른 사람의 답을 보지 말고 독립적으로 작성해 주세요.** 정답을 맞히는 시험이 아니라, 사전 정보 없이 사람이 무엇으로 인식하는지가 그대로 필요한 작업입니다. 저(의뢰자)에게 중간에 "이거 ~ 맞아요?"라고 묻지 마시고, 본인 판단만으로 작성해 주세요.

## 배경 정보 (이 정도는 참고하셔도 됩니다)

- 스캔 장소는 **산업용 로봇/모바일로봇을 다루는 실험실(연구실 겸 데모룸)** 입니다.
- 이미지들은 3D 점군(포인트 클라우드) 렌더링이라 실물 사진보다 거칠고, 색이 어둡거나 일부가 뚫려 보일 수 있습니다.
- 스캔 특성상 **벽·천장·기둥 조각 같은 "물체가 아닌 노이즈"가 후보에 섞여 있을 수 있습니다.** 물체가 아니라고 판단되면 그렇게 적어 주시면 됩니다 (예: "벽 조각인 것 같음").

## 시트 보는 법

- 시트 1장 = 후보 1개이며, 왼쪽 위의 **T3-01 ~ T3-41** 이 해당 후보의 ID입니다.
- 시트마다 같은 대상을 **여러 각도에서 본 렌더링 6장**이 있고, 아래 줄 마지막 2장은 확대 뷰입니다. 빨간 상자는 대상의 대략적 경계 표시일 뿐입니다.
- 오른쪽 위 **지도 그림**: 방을 위에서 본 지도이고, 빨간 표시(상자+원)가 이 대상의 위치입니다. 크기·위치 참고용입니다.
- 머리글의 "대략 크기"는 가로 × 세로 × 높이(미터)입니다.

## 작성 방법

`answer_sheet.csv` 파일을 열어 (엑셀/LibreOffice 가능) 각 ID 행에 다음을 채워 주세요:

| 칸 | 내용 |
|---|---|
| `label` | 무엇으로 보이는지 **자유롭게** (한국어/영어 모두 가능, 정해진 목록 없음). 예: "사무용 의자", "모니터", "mobile robot" |
| `confidence_1to5` | 확신도 1–5 (1 = 거의 추측, 5 = 확실) |
| `notes` | 선택 사항. 헷갈린 이유, 대안 후보 등 |

추가 규칙:

1. **한 시트에 여러 물체가 섞여 보이면, 보이는 것을 전부** `label` 칸에 적어 주세요. 예: "책상 + 모니터 + 의자 일부".
2. 도저히 알 수 없으면 `label`에 **"모름"** 이라고 적어 주세요 (이것도 유효한 답입니다).
3. 물체가 아니라 벽/천장/바닥 조각으로 보이면 그렇게 적어 주세요. 예: "벽 노이즈".
4. 빈 행 없이 41개 전부 채워 주세요.
5. 작성 후 파일을 저장해서 그대로 돌려주시면 됩니다. 종이 시트에 손으로 쓰셔도 됩니다.

감사합니다.
